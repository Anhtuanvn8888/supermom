# SUPER MÕM V7 — Map thật, 17 nhân vật

## V7 sửa gì?
- 6 map có ảnh nền khác nhau, không còn đổi mỗi màu/biển tên.
- Chọn map từ màn chính (**ĐỔI MAP**) hoặc khi đang dạo phố (**nút bản đồ**). Có thể bật/tắt đổi map tự động. Khi đổi map giữa ván, dòng người cũ được làm mới.
- Chọn đủ 17 nhân vật/skin trên 3 trang rõ ràng: 1–6/17, 7–12/17, 13–17/17.
- Vendor (Chị Trà Chanh) được thay bằng hình độc lập mới. Artist được lọc viền và nâng độ nét.
- Giữ cơ chế né, tăng tốc turbo, tap khẩu chiến, mini game khi thua và nút chốt điểm.

## Chạy game
Mở index.html bằng Chrome/Edge; game chạy ngay, không cần mạng. Các ảnh game đã nhúng trong index.html.

## Đưa GitHub Pages
1. Giải nén gói SUPER-MOM-V7-GITHUB.zip.
2. Upload `index.html`, `.nojekyll`, `README.md` lên thư mục gốc của repository GitHub.
3. Trong Settings > Pages, chọn Deploy from a branch > main > /(root) > Save.
4. Nếu đã có GitHub Pages, chỉ thay file index.html cũ và tải lại trang, có thể hard refresh bằng Ctrl+Shift+R.

Ghi chú: nhân vật là hình ảnh dựng theo phong cách 3D điều khiển bằng hoạt ảnh 2D; các map là ảnh nền minh họa, không phải thế giới 3D thời gian thực.
